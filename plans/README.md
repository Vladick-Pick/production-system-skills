# Планы развития

Этот каталог — единственная точка координации широких изменений репозитория.

## Активные планы

| План | Результат | Статус |
|---|---|---|
| [production-system-skills-v3.md](active/production-system-skills-v3.md) | Добавить контур развития через отклонения, гипотезы и эксперименты и восстановить полезную Рабочую панель | Сбор требований завершён по основной предметной модели; осталось четыре связанных проектных пакета |
| [production-system-skills-v2.md](active/production-system-skills-v2.md) | Переработать язык, поведение агентов, модель бизнеса, версионность, шаблон и BPMN/Camunda-проекцию | Шаблон v0.2 выпущен; migration runbook готов; живой пилот ждёт точных v0.1-книг и разрешения G-3, behavioral gate остаётся FAIL |

## Правила

- Активный план хранить в `plans/active/`.
- После завершения переносить его в `plans/archive/`, сохраняя принятые решения и доказательства проверки.
- Не вести параллельный статус той же работы в другом документе репозитория.
- Изменения нормативных контрактов, скиллов и шаблона начинать только после закрытия критических вопросов активного плана.

# Точка продолжения

Этот файл сохранён как совместимый вход для старых ссылок, но не владеет текущей задачей или планом работ.

Новая сессия должна:

1. прочитать [ПАСПОРТ.md](ПАСПОРТ.md);
2. проверить единственный рабочий статус в [plans/README.md](plans/README.md);
3. при проектировании нового релиза или изменении границы пакета прочитать [docs/PACKAGE-SCOPE.md](docs/PACKAGE-SCOPE.md).

Если активного плана нет, агент не продолжает историческую задачу по догадке: он исследует запрос пользователя и только после принятого решения создаёт новый план по правилам репозитория.

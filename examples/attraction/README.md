# Учебный пример: «кейс привлечения»

Пример вымышленный и показывает только метод.

В материалах встретился термин «кейс привлечения». Нельзя сразу записывать его как объект работы.

resolve-model-element проверяет четыре разные возможности:

1. переиспользуемая модель процесса;
2. один живой экземпляр процесса;
3. основной объект, состояние которого меняется;
4. CRM-запись, представляющая исполнение.

Проверочный сценарий:

> Один и тот же человек повторно входит в процесс. Возникает новый экземпляр? Если две CRM-карточки объединены, объединяются ли исполнения? Можно ли после отказа начать новый экземпляр?

Только после ответа можно выбрать исход: принять объект, изменить тип, разделить несколько смыслов, оставить термин синонимом либо отклонить его.

model-production-system использует уже принятое решение и строит действия в языке исполнителей. audit-production-system отдельно проверяет отказ, возврат, ожидание, дубликат и повторное открытие. maintain-production-system применяется только после принятого изменения.

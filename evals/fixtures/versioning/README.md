# Fixtures разреженного версионирования

`cases.json` задаёт вход и ожидаемый результат resolver без обращения к чату или Google Sheets. Поля `rows` намеренно универсальны: один алгоритм применяется отдельно к каждой версионной авторской таблице.

Правила:

1. цепочка `predecessor_version_id` должна быть линейной и конечной;
2. на один `stable_id` в одной версии разрешена одна редакция;
3. ближайшая операция `применить` включает редакцию;
4. ближайшая операция `исключить` исключает элемент;
5. в реестре версий допускается не более одного статуса `черновик`;
6. откат создаёт новую версию, а не открывает закрытую.

Успешный snapshot хранит только проверяемые поля `stable_id`, `source_version_id` и `value`. Ошибочные cases требуют точного `error_code`.

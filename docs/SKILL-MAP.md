# Карта запуска

| Пользовательский запрос | Основной скилл | Результат |
|---|---|---|
| «Что это за объект?» | resolve-model-element | Досье допуска и одно решение |
| «Добавь новый термин» | resolve-model-element | Определение до записи |
| «Собери систему с нуля» | model-production-system | Первая связная версия |
| «Наполни шаблон» | model-production-system | Канонические строки и проверяемые проекции |
| «Владелец принял изменение» | maintain-production-system | Новая версия и миграция |
| «Обнови схемы после изменения» | maintain-production-system | Синхронизированные представления |
| «Что забыли?» | audit-production-system | Read-only findings |
| «Почему схема не сходится?» | audit-production-system | Доказанное расхождение модели и проекции |

## Пограничные случаи

- Непонятен смысл хотя бы одного нового элемента — сначала resolve-model-element.
- Смысл принят, но система ещё не собрана — model-production-system.
- Система существует и изменение одобрено — maintain-production-system.
- Требуется только диагноз — audit-production-system.

Аудит не исправляет. Моделирование не переписывает принятую версию. Сопровождение не принимает решение за владельца. Семантический допуск не собирает весь процесс.

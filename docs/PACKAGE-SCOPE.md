# Граница пакета методологии и Agent Skills

Статус: канонический документ назначения и границы этого публичного репозитория.
Владелец решений: Владислав Богдан. Последняя проверка: 2026-08-19.

## Назначение

Репозиторий выпускает воспроизводимую технологию работы ИИ-агента с моделью
производственной системы: общий язык, четыре Agent Skills, канонический табличный
шаблон, миграции, примеры и автоматические проверки.

Пакет нужен агенту, чтобы разрешать смысл элемента, собирать, сопровождать и
аудировать модель в рамках точного выпущенного контракта. Он может применяться
самостоятельно с поддерживаемым шаблоном или закрепляться платформой как
version-pinned зависимость.

## Чем владеет репозиторий

- точными терминами и методологическими контрактами в корневых `references/`;
- четырьмя публичными скиллами и их самодостаточными копиями контрактов;
- schema, шаблонами, builder-скриптами и миграциями поддерживаемых релизов;
- fixtures, проверками, release notes и manifest публичного пакета;
- активным планом следующего выпуска в `plans/README.md`.

## Чем репозиторий не владеет

- полным продуктовым замыслом и целевым состоянием платформы;
- платформенным доменом, runtime-схемой, API, MCP transport, identity и tenancy;
- production-инфраструктурой, биллингом и внешними интеграциями;
- данными, решениями или рабочей истиной конкретной компании.

Полный продуктовый замысел принадлежит репозиторию платформы. Этот пакет не
сужает его до возможностей текущего стабильного релиза и не обещает ещё не
выпущенные возможности платформы.

## Контракт с платформой

Платформа закрепляет точный опубликованный release пакета по версии, commit и
контрольным суммам. Runtime не читает соседний checkout и не следует за moving
branch. Изменение методологии входит в платформу только после отдельного выпуска
пакета и явного обновления compatibility contract.

В обратную сторону продуктовая потребность платформы становится изменением этого
репозитория только через принятый план выпуска, обновление всех затронутых
артефактов и проверяемую миграцию. Приватные данные и платформенная инфраструктура
в публичный пакет не переносятся.

## Источники истины

- `ПАСПОРТ.md` — короткий контекст и текущее состояние репозитория;
- `references/` — нормативная методология;
- `templates/template-manifest.yaml` — текущий стабильный публичный артефакт;
- `plans/README.md` — единственный рабочий статус;
- `docs/ARCHITECTURE.md` — архитектура пакета;
- полный продуктовый замысел — `docs/PROJECT-INTENT.md` в репозитории платформы.

# Полный продуктовый замысел

Этот путь сохранён как совместимый указатель для старых ссылок. Полный замысел,
граница и целевое состояние продукта принадлежат репозиторию
[`business-ontology-platform`](https://github.com/Vladick-Pick/business-ontology-platform/blob/main/docs/PROJECT-INTENT.md)
и намеренно не дублируются здесь.

Текущий публичный репозиторий владеет только версионируемым пакетом методологии и
Agent Skills. Его назначение, граница и источники истины зафиксированы в
[`PACKAGE-SCOPE.md`](PACKAGE-SCOPE.md).

Исторические версии полного замысла в Git отражают прежнее расположение документа
и не являются параллельным источником продуктовых решений. Если доступ к приватному
репозиторию платформы отсутствует, это не разрешает восстанавливать или расширять
продуктовую границу по догадке.
